## CT-RF03-01 · Identificar corretamente o Dashboard

| Atributo | Definição |
| --- | --- |
| Requisito | RF03 |
| Situação | Reprovado |
| Banco | Não exigido para o objetivo delimitado do caso |
| Dados | Dados de teste compatíveis com o cenário. |

**DADO** que as pré-condições foram atendidas e o módulo Dashboard analítico está disponível,

**ENTÃO** O título deve identificar Dashboard ou o painel analítico, sem indicar Despesas Fixas.
